# BRODY PROJECT INTAKE CAPTURE BUFFER READONLY V1

## Purpose

Capture anything that enters the project field.

Examples:

- docs
- notes
- reports
- terminal outputs
- pointers
- artefacts
- zip files
- proofs
- scripts
- local audit outputs

## Boundary

- Captures traces: true
- Source tracking: true
- Human validation required: true
- Pending not canon: true
- Graphiti write: false
- Memory intake: false
- Memory decision: false
- Emits ACT: false
- Emits verdict: false
- Kernel mutation: false
- X108 runtime binding: false
- X108 merge: false

## Meaning

Brody can learn by preserving what arrives and preparing it for review.

But nothing becomes canon memory without human validation.
Nothing writes Graphiti from this layer.
Nothing touches X108.
