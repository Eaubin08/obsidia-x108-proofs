# METRICS STATUS POLICY

Status: UPDATED_FROM_AUDIT_MAPPING_V0

The Carte d'Identification Causale does not define final metric values yet.

Metric families can only be marked as:

- REPO_CONFIRMED
- PARTIAL
- NEEDS_REPO_AUDIT
- NEEDS_DOMAIN_CALIBRATION
- MISSING

Current mapping source:

registries/cic_metric_mapping_v0.yaml

Central rule:

Invariant > Reversibilité > Score > Projection

A score cannot authorize what an invariant forbids.
