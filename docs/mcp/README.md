## Role
MCP permission matrix. Tool access is not permission. The matrix defines which tools are available to which agents — but availability does not imply authority. X108 is the sole decision authority. Tool access = capability, not governance.

## Status
**MATRIX_ONLY** — Defines access. X108 grants permission.
