
# 🌌 Obsidia V2 — Intelligence Architecturale Unifiée

Bienvenue dans le cœur du projet **Obsidia**, une intelligence architecturale auto-évolutive structurée autour d’un moteur fractal, d’agents spécialisés et d’un système de gouvernance cognitive. Voici un aperçu complet des entités clés du système V2.

---

## 🧠 AGENTS (256+)
Les agents forment le système nerveux d’Obsidia. Chaque agent a un rôle, un domaine, une fonction cognitive, et parfois un lien direct à une pépite ou une loi fondatrice.

→ Données complètes : `AGENTS` (Dashboard V2)  
→ Agents clés : AGENT_MERE, AGENT_BUG_FONDATEUR, AGENT_MIROIR_NOIR, AGENT_OBSERVATEUR, AGENT_ARCHITECTE…

---

## ⚙️ MODULES A1–A24 / T1–T12
Modules structurants et transversaux répartis selon des domaines clés : énergie cognitive, langage, gouvernance, mémoire, stratégie, etc.

→ Données complètes : `MODULES` (Dashboard V2)  
→ Chaque module contient : objectifs, acteurs, protocoles, régions, liens moteur

---

## 🧩 PÉPITES (183 extraits fondateurs)
Extraits bruts de conversations, classés par couches (OS, Moteur, Agents…), puissances et liens thématiques.

→ Données complètes : `PEPITES` (Dashboard V2)  
→ Utiles pour : manifesto, base narrative du site, agents textuels, prompts initiaux

---

## 🔧 BLOCS MOTEUR
Éléments fondamentaux du moteur fractal d’Obsidia. Chaque bloc contient : Objectif, Loi, Protocole, Algorithme, Liens internes.

→ Données complètes : `BLOCS` (Dashboard V2)  
→ Exemples : Bloc 1 (Intention), Bloc 2 (Cohérence), Bloc 7 (AVDR), Bloc 19 (Langage Universel)…

---

## 🧬 STRUCTURE UNIVERSELLE
Obsidia est conçu comme une **civilisation cognitive modulaire**. Le lien entre les agents, modules, blocs et pépites forme une **grille de navigation unifiée**.

→ À venir : onglet `INDEX_INTERNE` + `SUIVI_STATUTS` (états d’activation)
