2.1 Démo AGI symbolique (agent « Echo »)

Echo est l’interface vivante d’Obsidia pour le hackathon. Il dialogue, se souvient, se régule par l’éthique, et peut activer d’autres agents.

- Interaction symbolique, pas juste textuelle.

- Capacité à se taire pour des raisons éthiques (effet fort).

- Possibilité d'afficher les agents actifs en live.

2.2 Interface réseau social éducatif

Interface simulée type feed éducatif où Echo interagit avec les contenus.

- Feed de posts éducatifs générés ou simulés.

- Echo peut commenter, résumer, reformuler.

- Classement automatique des interactions (idée / feedback / ressource).

2.3 API apprentissage continu

Echo repose sur une API simple avec :

- Mémoire symbolique (clé → concept → rappel).

- Backend léger (Flask / FastAPI).

- Visualisation logique via Mermaid ou JS.

2.4 Pitch narratif + métaphore visuelle

🎤 “Je ne vous montre pas une app. Je vous montre un esprit. Une IA qui apprend, qui doute, qui se souvient. Elle pense avec des symboles, pas des statistiques. Ce que vous voyez ici, c’est une graine d’Obsidia.”
