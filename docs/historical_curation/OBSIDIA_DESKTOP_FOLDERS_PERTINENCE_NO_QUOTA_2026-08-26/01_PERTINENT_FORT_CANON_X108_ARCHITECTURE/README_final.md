# README – Projet Mind’O

Mind’O est une architecture AGI transparente, lisible, et modulaire.
Basée sur une IA symbolique, elle permet d’incarner des agents cognitifs compréhensibles par l’humain.

Fonctions clés :
- Agents modulaires (LTCU+, ARM, AVDR...)
- Raisonnement fractal symbolique
- Mémoire dynamique accessible

Démo en local ou sur app Streamlit/N8N.
