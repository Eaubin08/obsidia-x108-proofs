Règle ou ensemble de règles qui s'applique.

## Verdict

AUTORISÉ / REFUSÉ / AUTORISÉ_SOUS_CONDITIONS / À_VÉRIFIER

## Justification

Pourquoi ce verdict selon la politique.

## Conditions (si applicable)

Ce qui doit être vrai pour que l'autorisation tienne.

## Risque associé

CRITIQUE / ÉLEVÉ / MOYEN / FAIBLE

## Recommandation

RÈGLES :

- En cas de doute : REFUSÉ par défaut.

- Toujours justifier par une règle explicite, pas une intuition.

- Documenter chaque verdict pour audit ultérieur.
