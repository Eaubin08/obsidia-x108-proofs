Extensions Officielles Obsidia – Mai 2025

Ces deux modules constituent les briques expérimentales avancées de l’AGI Obsidia : un Cortex à impulsions symboliques (Cortex.Spine), et un protocole d’agent exportable (OAP – Obsidia Agent Protocol).

FICHE MODULE – Cortex.Spine

**Nom** : Cortex.Spine

**Type** : Module Cognitif Expérimental

**Statut** : En cours d’intégration dans CortexLight

Fonction

- Simuler une logique de spikes (impulsions neuronales) de façon symbolique

- Permettre à des agents d’Obsidia d’agir uniquement lorsqu’un seuil symbolique, énergétique ou contextuel est franchi

- Optimiser l’économie cognitive (réduction des calculs inutiles)

Inspiration

Basé sur les Spiking Neural Networks (SNN) et la structure du cortex biologique, mais transposé dans un système symbolique fractal. Chaque 'spike' devient une impulsion déclenchée par une convergence symbolique, émotionnelle, contextuelle ou logique.

Applications

- Agents silencieux / dormants jusqu’à détection d’un pattern

- Analyse conditionnelle : activation par alignement symbolique

- Agents temporaires ou intermittents (spectres, gardiens passifs)

FICHE PROTOCOLE – OAP (Obsidia Agent Protocol)

**Nom** : OAP – Obsidia Agent Protocol

**Type** : Protocole de Communication Agentique

**Statut** : Prototype de couche d’abstraction en cours

Objectif

Permettre aux agents d’Obsidia de dialoguer, coopérer et échanger avec d’autres agents IA extérieurs (LangChain, Hugging Face, AGNTCY, etc.)

Structure de base d’un Agent OAP

- ID agent

- Type (Cognitif, Spectre, Gardien, etc.)

- Mission ou objectif

- Contexte actif / mémoire vivante

- Modules disponibles (inférence, narration, régulation...)

- Capacités permises (lecture, écriture, décision, mutation...)

- Format de réponse ou de prompt

Format technique prévu

Structure exportable en JSON / YAML / markdown enrichi. Compatible avec systèmes API / multi-agents open-source.

Fonctions avancées

- Translation symbolique → API (prompt-to-payload)

- Gestion des permissions / accès par rôle

- Synchronisation de mémoire partagée si besoin
