# Canonical Mapping (T/B/N/T11)

The Obsidia cognitive architecture was originally documented using multiple naming conventions.
This file provides a canonical mapping between the various T-cards, B-cards, N-cards, and other nomenclatures in the legacy documents.

## Card Families
- **T-cards (T1–T10)**: Primary thematic cards describing reasoning, agents, interfaces, outputs, narratives, etc.
- **B-cards (B1–B15)**: Bonus and extension cards including cognitive nodes, debug panels, archetype systems, memory modules and evolutionary systems.
- **N-cards (N1–N3)**: Key internal nodes for calibration, memory-to-action transduction, and sense-to-symbolic integration.
- **T11**: Provides extended reasoning typology beyond T1.

## Mappings
- **T1 (Fiche Raisonnements)** maps to reasoning modes C011–C040 and T11 further extends these to C028–C035.
- **T2 (Hiérarchie des Agents)** maps to agents C041–C100.
- **T3/T5 (Perception)** maps to sensory inputs C101–C123.
- **T4 (Interfaces) & T6/T9 (Sorties)** map to outputs C160–C175.
- **T7 (Portails)** maps to key and portal structures C124–C143.
- **T8 (Boucles)** maps to loop components C144–C159.
- **B-cards** provide extended modules from C106 through C163 and beyond.
- **N-cards** correspond to C263–C278, representing high-level cognitive nodes.

This mapping resolves naming collisions and ensures that every reference in the source documents aligns with a unique component ID in this spec.
