
RFC-0001: X–108 Temporal Safety Invariant
Status: Draft
Category: Safety / Middleware

Abstract
X–108 defines a temporal invariant preventing irreversible actions without demonstrated temporal stability.

Normative Rule
An irreversible action MUST NOT be executed unless X–108 returns ACT.

Security Model
Zero Trust Temporal Model: no decision is trusted without time exposure.

Compliance
Systems enforcing X–108 at the action boundary are X–108 Compliant.
