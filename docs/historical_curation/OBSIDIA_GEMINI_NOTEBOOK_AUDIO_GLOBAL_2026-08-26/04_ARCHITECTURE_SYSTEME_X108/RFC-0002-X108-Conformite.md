
RFC-0002 : X–108 — Conformité et Certification
Statut : Draft

Ce document définit les critères officiels de conformité et de certification
pour les systèmes déclarés « X–108 Compliant ».

Niveaux de conformité :
- Niveau 1 (L1) : Barrière X–108 présente avant toute action irréversible
- Niveau 2 (L2) : Mesures temporelles effectives (temps réel, stabilité)
- Niveau 3 (L3) : Tests adversariaux complets + auditabilité

Certification :
Un système certifié X–108 DOIT réussir l’ensemble des tests adversariaux,
y compris les boucles rapides et scénarios d’agent compromis.

Principe fondamental :
Une décision peut être instantanée.
Une action irréversible ne peut pas l’être.
