# P2 Bank Truth Proxy Scope

## Status

P2 BANK / TRUTH PROXY PACK

## Purpose

This pack creates a 100-case annotated proxy corpus for public banking evaluation.

It does not claim real banking ground truth.
It creates a reproducible offline proxy truth layer with:
- expected business decision
- expected minimum sovereign gate
- expected reason family
- batchable replay
- offline error analysis

## Families

- normal: admissible proxy cases
- review: review / analyze proxy cases
- blocked: non-admissible proxy cases

## What this pack proves

It proves that the public bank perimeter can be evaluated against:
- annotated business expectation
- minimum sovereign gate expectation
- offline confusion-style analysis
- reproducible batch execution

## What this pack does not prove

It does not prove:
- real banking truth
- regulatory approval
- production performance on live institutional data
