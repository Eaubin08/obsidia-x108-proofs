# PACK F — Besoin / mission / contexte

## Besoin énergétique
- type: hybride continu + impulsionnel
- priorité 1: stabilité
- priorité 2: vérité / preuve du régime
- priorité 3: autonomie
- rendement: secondaire au début
- horizon: court / moyen / long
- HOLD acceptable: oui
- SAFE_OFF acceptable: oui
- ON assisté toléré: oui, mais tracé

## Mission énergétique
- objectif run: identifier fenêtre viable, pas seulement point stable
- durée cible: variable, test court -> test long
- niveau minimal utile: seuil M2 actif stable
- condition arrêt acceptable: chute sous seuil HOLD prolongé
- condition échec: divergence / emballement / faux ON

## Contexte énergétique
- orientation: variable, test multi-orientation
- charge: modulable
- vibration externe: faible -> moyenne
- gravité/inertie: Terre, constante
- température: ambiante contrôlée
- support réel: rigide référence
- qualité alignement: contrôlée
- mouvement externe: OFF puis ON test
- GPS/position: non critique phase sandbox, pertinent si monde réel critique
