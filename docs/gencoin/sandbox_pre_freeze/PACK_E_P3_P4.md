# PACK E — P3 / P4

## P3 stockage
- type: inertiel / thermique / électrique selon proto
- capacité min/nom/max: à calibrer
- vitesse charge: rapide si inertiel/électrique, lente si thermique
- vitesse décharge: progressive
- pertes stockage: continues
- temps utile: court -> moyen
- coût maintien: faible -> moyen selon pertes

## P4 relance
- action physique réelle: impulsion externe / réamorçage / soutien temporaire
- cible réelle: M2 ou M4 ou M3
- coût R1/R2/R3: R1 faible, R2 moyen, R3 élevé
- durée: courte, bornée
- fréquence max admissible: limitée
- condition arrêt: seuil atteint ou vérité insuffisante
- délai minimal entre relances: obligatoire

## Séparation dure
Réserve/stockage ≠ coût cumulé de relance.

La relance sert à distinguer:
- autonomie vraie
- soutien temporaire
- agitation de maintien
- faux ON
