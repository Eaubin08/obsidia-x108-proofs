# PACK A — Familles physiques

## D primaire

### D1 inertiel / rotationnel
- grandeur primaire captée: rotation / inertie / transfert mécanique
- source réelle: masse en mouvement, rotor, axe
- pourquoi disponible: mouvement mécanique mesurable directement
- unité: rad/s, J, N·m
- plage attendue: faible -> élevée, à calibrer
- continuité: continue si rotation maintenue
- dépendance contexte: friction, masse, alignement, frottement air

### D2 pression / flux
- grandeur primaire captée: pression, débit, circulation
- source réelle: fluide / air / circuit
- pourquoi disponible: pression et débit mesurables par capteurs standards
- unité: Pa, m³/s, W
- plage attendue: variable, à calibrer
- continuité: continue si flux maintenu
- dépendance contexte: fuites, constrictions, turbulence

### D3 thermique / différentiel
- grandeur primaire captée: gradient thermique / transfert
- source réelle: source chaude/froide, dissipation
- pourquoi disponible: ΔT mesurable
- unité: °C, K, J, W thermique
- plage attendue: lente / faible à moyenne
- continuité: semi-continue
- dépendance contexte: isolation, dissipation, température ambiante

## C secondaire

### C1 électrique / signal
- grandeur primaire captée: signal, tension, courant
- source réelle: générateur, capteur, sortie conversion
- unité: V, A, W
- rôle: mesure / vérité / observabilité

### C2 vibration / oscillation
- grandeur primaire captée: oscillation / instabilité dynamique
- source réelle: mouvement, structure, perturbation
- unité: Hz, amplitude, g
- rôle: détection instabilité / dérive / emballement
