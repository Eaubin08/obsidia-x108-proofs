# MMonde V0 — minimal contract

Status: F3 implementation candidate for the first Obsidia release.

MMonde V0 materializes the smallest common situated-world grammar already dispersed across DomainState, GPS reality checks, context packets, provenance and proof surfaces.

Constitutional boundaries:

- OBSERVATION != TRUTH.
- WORLD_STATE != MEMORY.
- WORLD_STATE != COGNITION.
- TEMPORAL_ORDER != CAUSALITY.
- MMonde is representation-only and read-only.
- MMonde never decides and never acts.
- Decision authority remains KX108_ONLY.
- Domain-specific laws stay in domains.
- A causal claim marked CAUSAL_PROVEN requires explicit evidence references.

WorldObservationV0 carries identity/reference, state, relations, space, time, provenance/source references, uncertainty/contradictions, evidence and explicit causal status.

WorldStateV0 groups situated observations as a candidate reality at a validity time. It does not promote observations to truth and does not own memory or cognition.

This V0 deliberately does not implement general physics, semantic reasoning, biological laws, multimodal fusion, memory, cognition, or execution. Those layers connect through explicit adapters/contracts.
