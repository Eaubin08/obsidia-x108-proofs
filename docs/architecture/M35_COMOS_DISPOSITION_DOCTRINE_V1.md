# M35 COMOS — Disposition Doctrine V1

## 1. Status and authority

- Chapter: M35 — COMOS. Layer: cognition / pre-forge.
- Form: `M35_FORM=DOCTRINE_ONLY_DISPOSITION`. This document is the whole of M35 V1.
- Base: `COGNITIVE_FOUNDATION_V1=SEALED`, `FOUNDATION_REOPEN=NO`, M33 and M34 CLOSED.
- Basis: an independently certified M35 forensic, followed by explicit project-owner decisions (calibration to B11, selection and thresholds to B12, COMOS family 1 absorbed by B10 / World Model / Mmonde-REFLEX, Comos-Link excluded, primary historical document not required).
- Normative hierarchy: `FOUNDATION_SEAL > CURRENT_CANONICAL_ARCHITECTURE > THIS_DOCTRINE > HISTORICAL_GENEALOGY`.

M35 defines no layer, no runtime and no semantics of other layers. It records where each historical meaning attached to "M35 COMOS / calibration" now belongs.

## 2. Why M35 exists as a milestone

M35 is a disposition milestone. It exists only to:

- reconcile the several historical meanings of "COMOS";
- prevent calibration from being duplicated outside B11;
- prevent cosmology, physics and energy material from contaminating cognition;
- record ownership transfers;
- preserve the genealogy;
- establish explicit non-ownership boundaries.

## 5. Calibration

- `M35_OWNS_CALIBRATION=NO`
- `CALIBRATION_OWNER=B11`

This covers current cognitive calibration concepts — confidence, competence, reliability measurement and agent calibration — where applicable. M35 only records the ownership transfer; it does not define B11.

Historical calibration families and their disposition:

| Historical family | Disposition | M35 residual |
|---|---|---|
| Procedural (graph-link) calibration: link force, type, direction; keep/weaken/remove | relation qualification historically overlaps M33 / B11; removal used as selection belongs to B12 | NONE |
| ADeLe 18-axis calibration (agent-profile coefficients) | historical overlap with B7; B11 is the ownership candidate | NONE |
| Reliability-weighted ("external") calibration | `RELIABILITY_MEASUREMENT → B11`; `RELIABILITY_BASED_SELECTION → B12` | NONE |
| "Calibration Chaotique" | `CHAOTIC_CALIBRATION_STATUS=HISTORICAL_LABEL_ONLY_UNDEFINED`; not defined here | NONE |
| Domain calibration (GPS, Bank, Trading, sensors) | owned by those domains; `DOMAIN_CALIBRATION_IS_M35=NO` | NONE |

`CONFIDENCE != AUTHORITY`. `COMPETENCE != AUTHORITY`. Confidence or reliability never becomes authority.
