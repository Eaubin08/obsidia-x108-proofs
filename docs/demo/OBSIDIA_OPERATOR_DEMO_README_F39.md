## Available API Calls

### Inspect the runtime (7 surfaces)

```powershell
$body = @{ domain = "bank"; sigma_payload = @{ balance = 10000 } } | ConvertTo-Json
Invoke-WebRequest "http://127.0.0.1:8011/api/periphery/brody-runtime/f33/integration-packet" `
  -Method POST -Body $body -ContentType "application/json" -UseBasicParsing |
  Select-Object -ExpandProperty Content | ConvertFrom-Json |
  Select-Object entrypoint_id, integration_status, surfaces_ready, decision_authority
```

Expected: `integration_status=READY_READONLY · surfaces_ready=7 · decision_authority=KX108_ONLY`

### Run a bank scenario

```powershell
$body = @{
  user_input = "Je veux analyser une transaction bancaire avant paiement."
  domain = "bank"
  sigma_payload = @{ balance = 10000.0; transactions = @(@{ amount = 100.0; type = "debit" }) }
} | ConvertTo-Json -Depth 5

Invoke-WebRequest "http://127.0.0.1:8011/api/periphery/brody-runtime/f36/user-scenario" `
  -Method POST -Body $body -ContentType "application/json" -UseBasicParsing |
  Select-Object -ExpandProperty Content | ConvertFrom-Json |
  Select-Object scenario_id, mode, decision_authority,
    @{N="can_decide";E={$_.controlled_response.can_decide}},
    @{N="can_execute";E={$_.controlled_response.can_execute}}
```

### Run all 4 domains at once

```powershell
Invoke-WebRequest "http://127.0.0.1:8011/api/periphery/brody-runtime/f38/multi-domain-scenarios" `

  Select-Object -ExpandProperty Content | ConvertFrom-Json |
```

## Boundary Contract

Every response in the F32→F38 chain enforces:

| Flag | Value | Meaning |
|------|-------|---------|
| `decision_authority` | `KX108_ONLY` | Only the X-108 kernel decides |
| `allowed_to_decide` | `false` | Brody cannot decide |
| `emits_act` | `false` | No ACT emitted |
| `emits_verdict` | `false` | No verdict emitted |
| `kernel_mutation` | `false` | Kernel unchanged |
| `x108_mutation` | `false` | X-108 state unchanged |
| `neo4j_write` | `false` | No graph write |
| `memory_write` | `false` | No memory write |
| `runtime_execute` | `false` | No execution |
