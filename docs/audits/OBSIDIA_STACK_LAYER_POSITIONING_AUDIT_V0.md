# OBSIDIA_STACK_LAYER_POSITIONING_AUDIT_V0

## 1. Objet

Ce document fige le positionnement des couches Obsidia après l'identification de l'Inference Economy Layer et de la Domain Tool Absorption Layer.

## 2. Couches principales

| Couche | Rôle | Souveraineté |
|---|---|---|
| Kernel X108 | autorité d'admissibilité, HOLD/BLOCK/ACT, preuve, risque | souverain |
| Inference Economy Layer | mesure et réduction du coût d'inférence inutile | non souverain, mesureur |
| Brody Stack | interface cognitive / assistant gouverné | non souverain |
| Obsidure Stack | code, preuve, Lean, audit, réparation | non souverain |
| Domain Tool Absorption Layer | absorption des outils métier externes | non souverain |
| Domain Stacks | Bank, Trading, GPS, etc. | non souverain, traducteur métier |
| Receipts / Replay | preuve, audit, hash, coût, chemin | non souverain, preuve |

## 3. Synthèse

Le kernel gouverne l'action.

L'Inference Economy Layer gouverne le coût.

Brody gouverne l'interface cognitive.

Obsidure gouverne le code, la preuve et l'audit.

Les domaines gouvernent la traduction métier.

La Domain Tool Absorption Layer permet aux entreprises de brancher leurs propres outils.

Les receipts prouvent la route, la décision et le coût.

## 4. Principe central

Obsidia ne commence pas par demander au modèle quoi penser.

Obsidia commence par décider quel chemin a le droit d'exister.

## 5. Positionnement marché

La Big Tech centralise l'intelligence dans le calcul.

Obsidia redistribue l'intelligence dans la gouvernance du chemin.

## 6. Produit vendable

Obsidia peut être présenté par blocs :

- Kernel X108 seul
- Inference Economy seule
- Brody seul
- Obsidure seul
- Bank Stack
- Trading Stack
- GPS / Aviation Stack
- Domain Tool Absorption Layer
- Full Obsidia Stack

## 7. Conclusion

Obsidia remet du sens dans le calcul, de la gouvernance dans l'action, et de la mesure dans le coût.
