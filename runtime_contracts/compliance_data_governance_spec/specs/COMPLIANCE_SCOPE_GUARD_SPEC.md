# COMPLIANCE_SCOPE_GUARD_SPEC

Authority: KX108_ONLY
Runtime active: false

This spec defines compliance/data governance as a scope guard only.

It may mark:
- processing risk
- retention risk
- access risk
- privacy risk
- audit-readiness context
- human-review requirement

It may not certify:
- RGPD compliance
- legal compliance
- ISO compliance
- security posture
- personal data processing authorization
