# Politique de Sécurité et de Divulgation — Obsidia X-108 Proofs

## Portée de ce dépôt

Ce dépôt contient **uniquement** les éléments de vérifiabilité publique du système Obsidia :
- Les spécifications formelles (Lean 4, TLA+).
- Les scripts de vérification (vérificateurs Merkle, décisions).
- Les exemples de scénarios d'entrée.
- Le guide d'audit.

**Ce dépôt ne contient pas le moteur de production.** Les vulnérabilités liées au moteur propriétaire doivent être signalées via le canal privé ci-dessous.

## Signalement d'une Vulnérabilité

Si vous découvrez une vulnérabilité dans les scripts de ce dépôt :
1. **Ne pas ouvrir une Issue publique.**
2. Envoyer un email à : **security@obsidia.io**
3. Inclure : description, étapes de reproduction, impact potentiel.

Nous nous engageons à répondre sous 72 heures.
