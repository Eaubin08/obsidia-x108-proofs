# RGPD_COMPLIANCE_SCOPE_GUARD_SPEC

Boundary: RGPD_COMPLIANCE_SCOPE_GUARD
Authority: KX108_ONLY
Runtime active: false

RGPD materials can be used as scope guards, privacy-risk context, data-governance advisory labels, and future review checklists.

RGPD materials cannot:

- certify legal compliance
- authorize personal-data processing
- replace a DPO/legal review
- produce ALLOW/HOLD/BLOCK
- produce ACT
- decide educational data usage
- override X108

Required claim-scope:

- compliance_scope_guard=true
- legal_certification=false
- personal_data_processing_authorized=false
- runtime_allowed_now=false
- decision_authority=KX108_ONLY
