# AVDR — canon

AVDR = Accueil -> Vibration -> Déploiement -> Résolution.

## Phases
Accueil: perception, écoute, réception.
Vibration: réaction interne, friction, tri, tension.
Déploiement: action, expression, engagement.
Résolution: intégration, apprentissage, retour vers le calme.

## Fonction
AVDR est un protocole de lecture et de transformation vivante d'un état cognitif.

Il permet de positionner:
- état d'agent
- état d'interaction
- état de raisonnement
- phase vivante d'une structure en cours

## Fusion avec ADeLe / A2DR
ADeLe donne la mesure.
AVDR donne la dynamique.
Obsidia donne les organes et la signification structurelle.

## Synthèse
AVDR apporte la dynamique de transformation.
La Balance exponentielle apporte la pesée non linéaire de cette transformation.
