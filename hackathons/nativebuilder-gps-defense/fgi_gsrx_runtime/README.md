# FGI-GSRx Octave Runtime

Isolated hackathon runtime for attempting FGI-GSRx execution on FGI-SpoofRepo UT_DFMC.

This folder intentionally excludes:

- upstream FGI-GSRx source clones,
- original and derived RF datasets,
- `.mat` tracking/navigation outputs,
- heavy receiver run directories.

Only Dockerfile, compatibility shims, scripts, small manifests, reduced logs, and reports are eligible for Git.
