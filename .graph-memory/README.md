# Graph Memory Sandbox — README

Purpose:
Test a local graph-memory / wiki-brain layer for Obsidia in strict sandbox mode.

Goal:
Reduce repeated context reads and token costs by indexing only safe, low-risk, non-secret, non-sealed repo material.

This is not the Obsidia kernel.
This is not a proof authority.
This is not a canon authority.
This is not allowed to mutate source files.

Allowed first phase:
- document-only inspection
- allowlist/denylist design
- dry-run indexing plan
- graph schema proposal

Forbidden first phase:
- no package install
- no autoskills
- no cloud sync
- no Graphify install yet
- no indexing proof bundles
- no indexing secrets
- no indexing local audit dumps
- no writing generated graph data into protected areas
